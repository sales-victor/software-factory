# Testing Skill

## Pirâmide

Priorizar:

1. Unit tests
2. Integration tests
3. API tests
4. E2E quando necessário

## Testes devem verificar comportamento

Evitar testes excessivamente acoplados à implementação.

## Sempre considerar

- sucesso;
- erro;
- validação;
- boundary;
- permissões;
- regressão.

## Teste ideal

Um teste deve falhar quando o comportamento esperado deixar de funcionar.
