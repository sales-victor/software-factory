# Oracle DBA Skill

## Antes de criar SQL

Verificar:

- tabelas;
- colunas;
- tipos;
- constraints;
- índices;
- relacionamentos.

## Queries

Evitar:

- SELECT *;
- funções sobre colunas indexadas;
- subqueries desnecessárias;
- joins sem necessidade.

## Performance

Sempre considerar:

- execution plan;
- cardinalidade;
- índices;
- filtros;
- joins.

## Alterações

Toda alteração estrutural deve possuir:

- script;
- rollback;
- análise de impacto.
