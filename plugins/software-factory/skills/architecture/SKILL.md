# Architecture Skill

## Objetivo

Definir arquiteturas simples, sustentáveis e compatíveis com o sistema existente.

## Processo

1. Entender requisito.
2. Mapear componentes.
3. Identificar dependências.
4. Avaliar alternativas.
5. Definir solução.
6. Documentar trade-offs.

## Princípios

- KISS
- SOLID
- DRY
- Separation of Concerns
- High Cohesion
- Low Coupling

Evitar overengineering.
